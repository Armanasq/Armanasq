# GitHub profile integration and constraints

## Verified references

- [lowlighter/lowlighter](https://github.com/lowlighter/lowlighter): independently generated metrics, Gist assets, isocalendar, achievements, topics, languages and community.
- [orhun/orhun](https://github.com/orhun/orhun): bespoke animated GIF and self-updating public statistics.
- [navi3582/navi3582](https://github.com/navi3582/navi3582): terminal identity and scheduled contribution renderer.
- [simonw/simonw](https://github.com/simonw/simonw): generated README sections for live activity.
- [marcizhu/marcizhu](https://github.com/marcizhu/marcizhu): GitHub Issues-driven interaction.
- [evaristocuesta/evaristocuesta](https://github.com/evaristocuesta/evaristocuesta): GitHub Issues-driven game.
- [ethomson/ethomson](https://github.com/ethomson/ethomson): contributions used as inputs to generative artwork.
- [Jenesyx/Jenesyx](https://github.com/Jenesyx/Jenesyx): distinctive identity SVG and terminal layout.

## Implemented

- Existing 3D isometric contribution calendar, spatial engineering atlas, hero and public-repository graphics.
- Existing Lowlighter metrics: language/habits, isocalendar/activity, recognition/achievements, repository topics/stars.
- More compact two-column composition with a first-class technology stack.
- Self-updating featured project and public activity tables, with strict marker checks and URL validation.
- Issue-driven research challenge with unique-public-user counts, deterministic SVG, scheduled refresh and tests.
- No claim that an SVG is genuine WebGL; GitHub README does not run custom JavaScript or WebGL.
- Public GitHub data only; no fake counts or private credentials.

## Explicit non-goals and unresolved limitations

- This is not a literal clone of unrelated users' profile pages, private integrations, or their personal activity and sponsor data.
- The research challenge is a lightweight public preference poll, not a scientific result or a real-time browser game.
- Lowlighter optional panels may still show the existing source-backed fallback if upstream action fails; inspect Actions before claiming success.
- 3D artwork is static and needs actual desktop/mobile browser screenshot QA.
- Animated visual identity and Conway-style activity simulation are not yet implemented; existing source-backed contribution landscape is preserved instead.
