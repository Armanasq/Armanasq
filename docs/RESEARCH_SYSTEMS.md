# Research systems

This map is a conceptual research architecture, not an experimental result or a claim that all components are integrated into a single deployed product.

## Three pillars

1. Agentic reasoning: persistent memory, task transfer, generalization and metareasoning. [APEX-G](https://github.com/Armanasq/APEX-G).
2. Physical estimation: inertial attitude estimation, quaternion and DCM constraints, navigation and robustness. [6DoF IMU](https://github.com/Armanasq/End-to-End-Deep-Learning-Framework-for-Real-Time-Inertial-Attitude-Estimation-using-6DoF-IMU), [TE-PINN](https://github.com/Armanasq/TE-PINN-Transformer-Enhanced-Physics-Informed-Neural-Network-Quaternion-Orientation-Estimation).
3. Evidence systems: traceable retrieval, validation and research workflow infrastructure. [PhD Tracker](https://github.com/Armanasq/phd_tracker).

## Design rationale

The profile is a research portfolio, not a dashboard of decorative cards. Its main SVG assets are stored in the repository. Third-party metrics are retained in expandable sections instead of blocking the primary experience. The research diagram is readable without scripts and uses a 1260 × 520 coordinate system. Each linked project must be independently inspected before claiming a specific result.

## Remaining verification

Actual GitHub mobile/desktop browser screenshots, upstream image endpoint availability, and a successful published snake workflow have not been verified. No such verification is claimed.
